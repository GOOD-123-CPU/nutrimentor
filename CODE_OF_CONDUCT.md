# Code of Conduct

## Our Pledge

We want NutriMentor to be a welcoming project for learners, educators,
researchers, and maintainers. Participants are expected to communicate with
respect, assume good intent, and keep discussions focused on improving the
project.

## Expected Behavior

- Be kind and constructive in issues, pull requests, and reviews.
- Respect different levels of experience and different cultural backgrounds.
- Give feedback about code, documentation, and design choices rather than making
  personal attacks.
- Handle health, education, and user-data topics with extra care.

## Unacceptable Behavior

Harassment, discrimination, threats, doxxing, sexualized language or imagery,
and repeated disruptive behavior are not acceptable in this project.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or limit
participation when behavior violates this code of conduct. Serious concerns can
be reported privately using the security contact path described in `SECURITY.md`.
